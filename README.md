# Logan Grossman Concrete & Services LLC Website

This is a simple, professional one-page website for **Logan Grossman Concrete & Services LLC**, a family-owned concrete construction business. It includes a homepage, company info, services, and a contact form.

## Features

- Clean and modern design
- Mobile-friendly layout
- Company branding and contact info
- Editable services and about section
- Ready for free hosting (GitHub Pages, Netlify, or Vercel)
